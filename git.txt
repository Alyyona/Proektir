После изменений файлов:
# 1. Добавить все изменённые файлы
git add .

# 2. Сделать коммит (с описанием изменений)
git commit -m "Описание изменений"

# 3. Отправить на GitHub
git push
git status — посмотреть, что и где изменено. Команды git branch -M main, git remote add больше не нужны — уже настроено.
